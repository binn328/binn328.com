# Microsoft PC Manager
![[Pasted image 20260627211009.png]]
바로 [Microsoft PC Manager](https://pcmanager.microsoft.com/ko-kr)입니다. 

엥? 마소 앱이면 그거 쓰레기 아닌가요? 라고 말할 수도 있지만, 이 녀석은 좀 다릅니다. 마이크로소프트는 쓸모없는 AI 코파일럿을 광고할게 아니라 이런걸 광고해야하는데...

아무튼 설치 후 프로그램을 한 번 살펴봅시다.
![[Pasted image 20260627211210.png]]
프로그램은 굉장히 심플하게 생겼습니다. 이런 프로그램에 꼭 들어가는 메모리 정리, 디스크 정리 기능이 첫 화면에 보이네요. 하지만 우리는 팝업 광고를 차단하려고 왔습니다. 해당 기능은 *보호 - 팝업 관리* 탭에서 확인할 수 있습니다.
![[Pasted image 20260627211343.png]]
해당 설정에 들어와서 *찹업 차단 사용*을 해주면 이런 화면이 보이게 됩니다. 기본적으로 앱들이 사용하는 팝업을 보여주는데, 팝업을 표시하는 프로그램이 바로 뜨길래 즉시 팝업 차단을 해주었습니다. 그리고 다시 앱을 켜보면...
![[Pasted image 20260627211518.png]]
놀랍게도 우측 하단의 광고, 그리고 업데이트를 안 하면 앱을 끌 때마다 표시하는 업데이트 안내가 사라졌습니다! 코파일럿같은 쓰레기만 양산하다가 간만에 괜찮은 프로그램을 출시했는데 이런걸 광고할 것이지...

아무튼 읽어주셔서 감사합니다.
